Сделай в папке vibe/ веб-приложение на Django для подготовки к экзамену.

Что нужно:
- Темы (например, "Python", "Базы данных") и вопросы к ним с 3-4 вариантами ответа, один правильный.
- Регистрация и вход пользователей.
- Пользователь выбирает тему и проходит тест из 10 случайных вопросов этой темы.
- После теста — страница результата: сколько правильных, где ошибся и какой ответ был верным.
- Страница "Мои результаты" с историей попыток.
- Вопросы и темы добавляются через админку Django.
- Команда manage.py для загрузки демо-данных: 2-3 темы по 10+ вопросов.
- Простой аккуратный дизайн (можно Bootstrap через CDN).

Техника:
- База PostgreSQL. Всё запускается через docker compose: сервисы web и db.
- Все настройки и пароли — из переменных окружения через файл .env; добавь .env.example. В .gitignore должен быть .env.
- Приложение будет открываться через GitHub Codespaces по адресу вида https://*.app.github.dev — учти ALLOWED_HOSTS и CSRF_TRUSTED_ORIGINS.
- Напиши несколько тестов.

Сверяйся с документацией через context7. В конце напиши, какими командами всё запустить.
