# AGENTS.md

## О проекте
Учебная лабораторная работа: веб-приложение для подготовки к экзамену
(банк вопросов по темам, прохождение тестов, статистика результатов).

Стек: Python 3.12, Django 5.2 LTS, PostgreSQL 17, Docker Compose.
В SDD-версии дополнительно используется Valkey как кэш.

## Структура репозитория
- `vibe/` — версия приложения, сделанная вайбкодингом (оценка «4»)
- `sdd/` — та же версия, сделанная по Spec-Driven Development (оценка «5»)
- `docs/` — отчёты по этапам и скриншоты
- `.opencode/skills/` — skills для агента

## Команды
Запускать из папки нужной версии (`vibe/` или `sdd/`):
- Запуск: `docker compose up --build -d`
- Миграции: `docker compose exec web python manage.py migrate`
- Тесты: `docker compose exec web python manage.py test`
- Логи: `docker compose logs -f web`

## Правила работы
- Общайся со мной на русском. Код, имена переменных и функций — на английском.
- Перед изменениями кратко опиши план, потом выполняй.
- Для актуальной документации Django, PostgreSQL и Valkey используй MCP context7,
  а не только свою память.
- Секреты (пароли, SECRET_KEY) — только в `.env`, который не коммитится.
  В репозиторий кладётся `.env.example` с примерами значений.
- После изменений в коде запусти тесты и убедись, что они проходят.
- Не меняй файлы, не относящиеся к задаче.
- Для коммитов используй skill `git-commit`. Не делай `git push` без моей просьбы.
